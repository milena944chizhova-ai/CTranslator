## Поддерживаемое подмножество языка C

```c
// Объявление переменной
int a;

// Присваивание
a = 5 + 3 * 2;

// Ввод
scanf("%d", &a);

// Вывод
printf("%d\n", a);

// Условный оператор
if (a > b) {
    max = a;
} else {
    max = b;
}
```

**Поддерживаемые операции:**
- Арифметические: `+`, `-`, `*`, `/`
- Сравнения: `==`, `!=`, `<`, `>`, `<=`, `>=`
- Унарный минус: `-a`
- Скобочные выражения: `(a + b) * c`

## Структура проекта

```
CTranslator/
├── CTranslator.csproj       # файл проекта .NET
├── README.md                # документация
├── src/
│   ├── Token.cs             # типы лексем
│   ├── Lexer.cs             # лексический анализатор (конечный автомат)
│   ├── AstNodes.cs          # узлы синтаксического дерева (AST)
│   ├── Parser.cs            # синтаксический анализатор (расширенное предшествование)
│   ├── SemanticAnalyzer.cs  # семантический анализатор + таблица символов
│   ├── Interpreter.cs       # интерпретатор (выполнение по AST)
│   └── Program.cs           # точка входа
└── tests/
    ├── input.txt            # основной тест (max двух чисел)
    ├── test_arith.txt       # тест арифметических выражений
    ├── test_nested_if.txt   # тест вложенных условий
    ├── test_divzero.txt     # тест деления на ноль
    └── test_semantic_err.txt # тест семантической ошибки
```

## Сборка и запуск

### Сборка
```bash
cd CTranslator
dotnet build
```

### Запуск с тестовым файлом

```bash
# Основной тест (нахождение максимума двух чисел)
dotnet run -- tests/input.txt

# Тест арифметики
dotnet run -- tests/test_arith.txt

# Тест вложенных условий
dotnet run -- tests/test_nested_if.txt

# Тест деления на ноль
dotnet run -- tests/test_divzero.txt

# Тест семантической ошибки
dotnet run -- tests/test_semantic_err.txt
```

### Запуск собственной программы
Создайте файл `myprog.txt` и запустите:
```bash
dotnet run -- myprog.txt
```

## Выходные файлы

После успешного запуска в рабочей директории создаются:

| Файл | Содержимое |
|---|---|
| `lexer_output.txt` | Таблица лексем (токенов) |
| `ast_output.txt` | Синтаксическое дерево (AST) |
| `symbols_output.txt` | Таблица символов |

## Пример работы

**Входной файл (`tests/input.txt`):**
```c
int a;
int b;
int max;

scanf("%d", &a);
scanf("%d", &b);

if (a > b)
{
    max = a;
}
else
{
    max = b;
}

printf("%d\n", max);
```

**Пример консольного сеанса:**
```
─── 1. Лексический анализ ───
  Всего лексем: 52
  Лексических ошибок не обнаружено.
  Таблица лексем → lexer_output.txt

─── 2. Синтаксический анализ (расширенное предшествование) ───
  Синтаксический анализ завершён успешно.
  Синтаксическое дерево → ast_output.txt

─── 3. Семантический анализ ───
  Переменных объявлено: 3
  Семантических ошибок не обнаружено.
  Таблица символов → symbols_output.txt

─── 4. Выполнение программы ───

Введите значение для a: 7
Введите значение для b: 12
12

=== Состояние памяти ===
  a          = 7
  b          = 12
  max        = 12
```
